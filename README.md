# Pcb-Defects-Detection
Чтобы запустить все разом, использовать Start.bat. Может выдать ошибку подключения к базе данных, требует PstgreSQL -> БД pcb_defects -> таблица inspections.
В Back лежит API и работа модели. В папке "Images To Detect" содержатся изображения, которые можно проанализировать с помощью перемещения в папку "images". Оттуда почти сразу удалится и в каталоге "out" появится картинка с отмеченными дефефктами, а в "json" JSON с количеством дефектов. Если БД будет подключена, появится запись с названием, id, количеством дефектов и временем проверки.
